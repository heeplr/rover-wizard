1"""rover_wizard.vehicle.log_transfer - listing, downloading and erasing the vehicle's onboard logs over MAVLink. 

2 

3ArduPilot's log protocol (AP_Logger_MAVLinkLogTransfer.cpp): 

4* LOG_REQUEST_LIST -> one LOG_ENTRY per log: its id (its position in the list, 1 = the oldest, NOT the number in the 

5 file name on the SD card), the number of logs, its time (UTC, 0 if unknown) and size. 

6* LOG_REQUEST_DATA(id, offset, count) -> LOG_DATA pieces of up to 90 bytes, until `count` bytes or the end of the log 

7 have been sent. ArduPilot sends what its file read returns: a shorter piece (or one of 0 bytes after a read error) 

8 ends the transfer early, and pieces asked for later may start anywhere. 

9* One transfer at a time, and it never times out: until it has sent everything asked for, a LOG_REQUEST_DATA from the 

10 same link is silently dropped and a LOG_REQUEST_LIST answered only with "Log download in progress" - also when the 

11 program that asked is gone (an interrupted download of a large log keeps the vehicle busy for minutes). 

12 LOG_REQUEST_END ends it at once, so the wizard sends it before every request. 

13* LOG_ERASE erases all logs - MAVLink has no message to erase a single one. 

14* While the vehicle is armed, ArduPilot ignores all of it ("Disarm for log download"). 

15"""

62def _check_pieces(ranges: list) -> list: 

63 """(offset, length) of up to RESUME_CHECKS pieces spread over the received ranges: at the start of the first, 

64 in the middle one and at the end of the last.""" 

65 first, middle, last = ranges[0], ranges[len(ranges) // 2], ranges[-1] 

66 pieces = { 

67 (first[0], min(PIECE_SIZE, first[1] - first[0])), 

68 ((middle[0] + middle[1]) // 2, min(PIECE_SIZE, middle[1] - (middle[0] + middle[1]) // 2)), 

69 (max(last[0], last[1] - PIECE_SIZE), min(PIECE_SIZE, last[1] - last[0])), 

70 } 

71 return sorted(pieces)[:RESUME_CHECKS]

156 in a row bring nothing new although the link was up, or the link stays lost for LINK_WAIT_SECONDS; what 

157 arrived until then is in snapshot()."""
