1"""rover_wizard.steps.distance_sensors - the "Distance sensors & object avoidance" step. 

2 

3Rangefinders (RNGFNDn_*) measure one distance in one fixed direction - forward for obstacles, down as a boat's 

4echosounder. Proximity sensors (PRXn_*) report distances in several directions around the vehicle, and they are 

5what ArduPilot's object avoidance uses. The proximity type "RangeFinder" bridges the two: it feeds every 

6horizontally pointing rangefinder (orientation 0-7) into the proximity system (AP_Proximity_RangeFinder.cpp). 

7 

8Type lists use ArduPilot's own names; which types need a serial port or an I2C address was read from the driver 

9selection in ArduPilot's AP_RangeFinder.cpp / AP_Proximity.cpp. 

10"""
